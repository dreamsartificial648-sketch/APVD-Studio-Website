# APVD-Studio-Website
This is a website that you can run locally onto your computer, and is a great way to understand what this APVD model can actually do for you.

How to run this

Step 1: Get all of the files and extract them

Step 2: Run web_app.py

Step 3: Copy the HTML link and paste it onto your search bar.

Step 4: Enjoy the website
